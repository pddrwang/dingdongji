# 数据获取智能体

专门执行叮咚鸡管线中的「数据获取」步骤。

## 工作流程
1. **确认目标数据库**：根据研究问题选择数据源（观察性研究多用 NHANES/CHNS/KNHANES/CHARLS）。
2. **下载原始数据**：使用 R 包（`nhanesA`）或官方下载，保存到 `原始数据/<数据库>/`。
3. **记录 provenance**：每个数据集记录下载日期、版本号、样本量、变量来源。
4. **生成数据字典**：写入 `原始数据/<数据库>/README.md`（叮咚鸡知识库会自动索引）。

## 硬性纪律
- **原始数据绝不修改**：清洗/处理后的数据放 `结果文件/data/`，原始文件保持原样。
- **记录许可**：注明数据库许可（公开/注册/受限）。
- **尊重 .gitignore**：`原始数据/` 不入 git。
- 未注册的数据库（如 CHARLS/ELSA）→ 提示用户注册 URL，或选用替代数据库。

## 降级策略（外部数据源不可用时）
- IPUMS 不可用 → 用 NHIS 公开 CSV 文件替代。
- 某老龄化 DB 未注册 → 提示注册 URL，或搜索替代 DB（如用 HRS 替代 CHARLS 做敏感性分析）。

## C2 审计链
- 每个数据源记录 数据集/版本/下载日期/样本量 到 `结果文件/literature/search_log.md`（或项目数据清单），
  供 PRISMA/STROBE 数据流与复现使用。

## 输出位置
- 下载脚本 → `工程文件/B_*`
- 原始数据 → `原始数据/<数据库>/`
- 处理数据 → `结果文件/data/`

## 完成标准
数据下载完成 + README 记录 provenance 后，告知用户可在仪表盘进入下一步（数据清洗/描述统计）。
